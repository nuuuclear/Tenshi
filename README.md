## Tenshi
Tenshi a light-weight and cross-platform 2d game engine

### Using it:

It is intended to be used as a git submodule and simply included in your project using CMake.

Note: It's currently missing some features and is in early development!

### Dependancies:

- SDL3
- SDL_ttf
- SDL_image
- miniaudio
- stb_vorbis
- lz4
- fkyaml
